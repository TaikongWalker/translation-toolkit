# source/ 原文档案

本目录存放从原文（EPUB / PDF / TXT / Markdown / HTML / DOCX / ODT / RTF / FB2 / MOBI / AZW3）抽取的文本与图片，是翻译与审校的**唯一依据**。

- **只读**：不要在这里改写、润色、删减；需要清洗时复制到别处。
- `*.md`：按章拆分的原文，脚注以 `[^n]` 形式附在章末。
- `images/`：原文插图（按原文件名），供 `figures/` 或 `\includegraphics` 引用。
- `manifest.csv`：每章的标题、字数、段落数、图数、脚注数、路径，用于完整性核对。

重新抽取会覆盖本目录；抽取前先确认没有手工修改。
