# 决策记录

> 所有不可从代码/术语表推出的重大决定都记在这里：书名译法、作者译名、术语改译、体例变更、段落合并。格式：日期 / 决策 / 理由 / 影响范围。

## 2026-01-01 示例：书名暂定

- 决策：书名暂译为《中文书名》，副题暂译“……”。
- 理由：直译可保留原文双关；通行译名尚未确定。
- 影响：封面、页眉、PDF 元数据、引用格式。
- 状态：待确认。

## 模板：术语改译流程

1. 在 `glossary/terms.csv` 修改 `target`，旧译名移入 `forbidden`；
2. 全书搜索旧译名并替换；
3. 在本文件记录日期、旧译、新译、理由；
4. 运行 `check.py` 确认无残留。
