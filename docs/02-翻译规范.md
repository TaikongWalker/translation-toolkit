# 翻译规范

本规范是默认体例。项目有特殊要求时，在 `notes/style.md` 中覆盖，并注明“覆盖本规范第 X 条”。

---

## 1. 总原则

**准确优先，风格对等，可读性服从前两者。**

- “准确”指信息、逻辑、语气、指代、注释关系均不变；
- “风格对等”指原文的语域、节奏、修辞密度在译文中大致可感，而不是一律改成四平八稳的书面语；
- “通顺”不等于“归化”：不能为了顺口删掉限定、反讽或陌生感。

判断标准：**懂原文的读者读译文，能获得与读原文相近的理解与感受；不懂原文的读者，读到的是一本正常的中文书。**

---

## 2. 忠实度

### 2.1 不可省略

以下内容一律保留，且位置对应：

- 限定语、插入语、同位语、破折号补充；
- 重复（作者的强调手段，不要“优化”掉）；
- 模糊限定（perhaps, apparently, as it were, so to speak）；
- 反讽、双关、反话（译不出时加注，不改成直白陈述）；
- 引文出处、页码、年份、档案编号；
- 脚注、尾注、图注、表注、题词、献词、致谢、附录、索引。

### 2.2 不可增写

- 不替作者解释隐含前提；
- 不补充原文没有的过渡句；
- 不把术语的学术争论“讲清楚”；
- 必要的背景说明只能进**译者注**，并与正文明确分开。

### 2.3 句法重组

允许且鼓励在**段落内**重组句子：

- 英语长句拆为 2–3 个中文短句，但保留原有的逻辑层级（主句—让步—条件—结果）；
- 连续短句可合并，前提是不丢失主语切换与时间顺序；
- 被动转主动时，确认施事者是否原文明确；不明确则用无主句或“有人/人们”，不臆造主语；
- 名词化结构（the construction of…）转动词结构，但保留动作的施受关系。

### 2.4 歧义处理

原文有歧义时：

1. 优先保留歧义（中文也能两解）；
2. 不能保留时，选最符合上下文的解释；
3. 另一解有实质影响时，加译者注说明；
4. 禁止“折中翻译”把两种意思揉成一句。

## 3. 术语与专名

### 3.1 唯一权威

`glossary/terms.csv` 是唯一权威。已 `final` 的词不得改写；需要改，先改表并在 `notes/decisions.md` 记录，再全局替换。

### 3.2 首次出现

- 人名、地名、机构、作品：首次出现可用 `\term{中文}{原文}`，之后只用中文；
- 学术术语：首次出现括注原文；作者作为分析对象反复使用的外来词，保留原文并加注；
- 缩写：首次“中文全称（English Full Name, ABC）”，之后用缩写。

### 3.3 人名

- 西文姓名：`名·姓`，中间用间隔号 `·`（U+00B7），不用句点；
- 已有通行译名从通行，不按发音另造（Tolstoy → 托尔斯泰；Nietzsche → 尼采）；
- 俄语人名按通行音译：`-ov/-ev` → `-夫`，`-sky/-skii` → `-斯基`，`-ova` → `-娃`，`-vich` → `-维奇`；
- 同一人物在全书只用一种译名；昵称（如 Bill、Liz）保留昵称感，首次可括注全名。

### 3.4 地名

- 用标准译名（Paris → 巴黎、London → 伦敦）；
- 已更名城市按历史语境处理：正文用当时名称，首次可注今名；
- 小地名音译，首次括注原文。

### 3.5 机构与作品

- 机构用通行简称，首次给全称；
- 书名、文章、电影、歌曲、画作用《》；单篇文章也可用《》；
- 原文书名首次出现括注，之后只用中文；
- 系列名、奖项名、出版社名按通行译法。

### 3.6 外来语（俄语等）

原文以斜体出现的外来词，分两种情况：

| 类型 | 处理 |
|---|---|
| 普通外来词（kindergarten, zeitgeist） | 首次“中文（原文）”，之后中文 |
| 作者的核心分析概念（habitus, Gemeinschaft） | 保留原文斜体，首次加译者注解释；中文可用引号夹注 |
| 原文语言的原词（非转写） | 一般不引入正文；必要处放脚注 |

## 4. 语法与逻辑

翻译时逐项核对：

- **否定**：not…until、hardly、scarcely、no longer、双重否定；
- **情态**：may / might / could / must / should / supposedly / allegedly → 中文用“可能/也许/必须/应当/据说/据称”，不一律译“会”；
- **时态与体**：英语过去完成时体现的“先发生”，中文用“此前/已经/当时已”；俄语完成体/未完成体的反复性、持续性，用“屡次/不断/一度/终于”等副词体现；
- **条件与虚拟**：if / would have / were to → “如果……本来会/倘若”；
- **让步**：although / while / even as → “尽管/虽然/而与此同时”，注意 while 不总是“当……时”；
- **因果**：since / as / for 的因果强度弱于 because，不一律译“因为”；
- **指代**：this / that / it / they / the former → 明确指向，必要时重复名词，不用一连串“这/那”；
- **插入语**：保持插入位置或移到句首并用逗号隔开，不吞掉；
- **引语**：直接引语用引号，间接引语不改视角；说话人提示语位置可调整，但说话人不能换。

## 5. 标点与格式

### 5.1 中文标点（全角）

| 用途 | 符号 | 说明 |
|---|---|---|
| 逗号、句号 | ，。 | 不用 `,` `.` |
| 顿号 | 、 | 并列词语 |
| 分号、冒号 | ；： | |
| 问号、叹号 | ？！ | |
| 引号 | “”‘’ | 双层：外双内单 |
| 书名号 | 《》〈〉 | 书名、篇名、作品名 |
| 破折号 | —— | 两个 em dash，占两格 |
| 省略号 | …… | 两个三连点，共六点 |
| 间隔号 | · | 人名、书名内部分隔 |
| 连接号 | — / ～ | 数字范围用浪纹或一字线，按项目统一 |

### 5.2 中英混排

- 中文与西文、数字之间**不加空格**（LaTeX/xeCJK 自动处理间距）；源文件中也不要手打空格；
- 西文括号用于括注原文时，括号内用西文标点；
- 英文缩写后的句点保留（e.g., etc.），但中文句末仍用中文句号；
- 数字：年份、页码用阿拉伯数字；概数、成语用汉字（“三四十人”“千方百计”）；百分比用 `%`；世纪用“20 世纪 80 年代”。

### 5.3 引文

- 短引文（≤ 3 行）随文加引号；
- 长引文（> 3 行）独立成段，左右缩进，字号略小，不加引号；
- 引文内的省略用 `……`，不用 `...`；引文内补充用 `〔〕`；
- 原文引文有页码，译文保留页码（不改成中文版页码，除非有中译本并注明）。

### 5.4 斜体

- 西文书名、外来词、强调用 `\textit{}`；
- 中文不用斜体；中文书名用《》，强调用着重号（如需，用 `\emph` 自定义）；
- 原文斜体的俄语转写词，译文保留斜体 + 中文夹注。

## 6. 注释规范

### 6.1 三类注释

| 类型 | 标记 | 处理 |
|---|---|---|
| 原文脚注 | `\footnote{}` | 全译，编号与原文对应；不合并、不删减 |
| 译者注 | `\zhu{}` | 以“译者注：”开头，说明背景、双关、译名理由；尽量短 |
| 原文夹注 | 正文括号 | 原样保留，不改成脚注 |

### 6.2 原文脚注

- 每条原注都要译，包括纯参考文献式注释（作者、年份、页码保留原样）；
- 原注中的拉丁/俄文书名保留原文，可加中文译名；
- 原注编号若与正文引用绑定（如“见注 12”），译文编号必须一致；LaTeX 自动编号时，用 `\label`/`\ref` 或手动核对；
- 原注跨页长注不拆成多条。

### 6.3 译者注

- 只在必要时加：文化背景、双关无法保留、术语争议、原文事实错误、历史事件；
- 每条不超过 3 行；能并入正文的常识不加注；
- 不借译者注发表译者观点；
- 位置：紧跟需要说明的词句之后；使用独立编号（“译注 1、译注 2……”），不占用原注编号，确保原注号与原文一一对应。

### 6.4 图表注

- 图注、表注、图例、坐标轴标签、来源行全部翻译；
- 图片内的文字（照片中的标语、广告、手写笔记）不修图，在图注中说明原文与译文；
- 保留“来源：……”“作者译”等 credits；
- 图号沿用原文（图 2.1 仍是图 2.1），便于对照。

---

## 7. 图表与版式

- 每幅图必须有图注；正文必须有引用（“如图 2.1 所示”）；
- 图不跨页、不与图注分离；宽图可旋转 90°；
- 表格用三线表；表头跨页重复；数字右对齐/小数点对齐；
- 原文的表格若为排版用表格（非数据表），可转为列表，但需在译者注说明；
- 地图、谱系图、流程图：优先重绘为矢量图；不能重绘则保留原图并译图注；
- 图片分辨率 ≥ 300 dpi；灰度图检查对比度。

## 8. 风格对等

### 8.1 语域

- 学术专著：保留论证的限定与层次，允许长句，但每句中文必须能读懂；避免“笔者认为”式添加；
- 访谈/口述：保留口语的停顿、重复、不完整句；不改成书面语；
- 讽刺/幽默：优先保留反讽结构；不能保留时，用中文的反讽语气 + 译者注，不解释成直白批评；
- 抒情/文学：保留意象与节奏，不堆砌四字格。

### 8.2 句长与节奏

- 原文以短句为主的段落，译文不要合成长链；
- 原文以长句铺陈的段落，译文可拆，但保留“总—分—转折—收束”的节奏；
- 段落长度大致对应；不把一段拆成三四段，除非中文阅读确实需要。

### 8.3 避免翻译腔

常见病灶与改法：

| 病灶 | 改法 |
|---|---|
| 的的不休 | 拆句、动词化、删冗余修饰 |
| 被动泛滥 | 明确施事或改无主句 |
| 名词化堆叠 | “对……进行……的分析” → “分析……” |
| 连接词冗余 | 删“因此/然而/此外”，靠语序衔接 |
| 代词过多 | 重复名词或省略 |
| 一律“进行/做出/给予” | 直接用实义动词 |
| 生硬直译习语 | 找中文对应表达，找不到则直译加注 |

### 8.4 风格表（每项目填写 `notes/style.md`）

- 目标读者与语域；
- 句长偏好（平均字数、上限）；
- 四字格使用限度；
- 外来语保留策略；
- 称呼与语气（你/您、我们/笔者）；
- 作者标志性修辞的处理方式；
- 允许的归化程度（0–3 级）。

## 9. 常见错误清单

- [ ] 漏译插入语、括号内容、破折号补充
- [ ] 把 `while` 一律译“当……时”
- [ ] 把 `since` 一律译“因为”
- [ ] 把 `this` 译“这”但指代不明
- [ ] 双重否定译反
- [ ] 数字、年份、百分比抄错
- [ ] 人名前后不一致（同一人两种译名）
- [ ] 术语随上下文改译
- [ ] 原文脚注被合并或删除
- [ ] 图注只译一半
- [ ] 英文引号、半角逗号混入中文
- [ ] 省略号用 `...`、破折号用 `--`
- [ ] 中文里手打空格
- [ ] 把作者的反讽译成正面陈述
- [ ] 为“通顺”删掉限定语（may, often, in some cases）

---

## 10. 交付格式

- 源文件：LaTeX（UTF-8，XeLaTeX 编译）；
- 成品：PDF（A5/170×240mm，按项目定）；
- 附带：术语表、背景卷宗、决策记录、进度表；
- 文件名：`<slug>.pdf`；版本号写入 PDF 元数据与版权页。
