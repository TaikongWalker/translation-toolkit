# 质检清单

分「自动检查」与「人工检查」两部分。自动检查只抓机械问题，不能替代阅读。

---

## 1. 自动检查

### 1.1 命令

```powershell
# 在项目目录
python ..\..\scripts\check.py --project .

# 只看摘要
python ..\..\scripts\check.py --project . --summary

# 构建时自动运行
.\scripts\build.ps1
```

### 1.2 检查项

| 编号 | 检查 | 判定 | 级别 |
|---|---|---|---|
| A1 | 已定名术语的原文形式残留在译文中 | 列出位置与上下文 | 提示 |
| A2 | 使用了 `forbidden` 列登记的禁用变体 | 每个出现都报 | **错误** |
| A3 | 本章应引入的术语未在译文中出现（按 `first_seen` 判断） | 列术语 | 提示 |
| A4 | 中文旁的半角标点（`,;:!?`） | 列出 | **错误** |
| A5 | 中文文本中使用英文引号 `"` `'` | 列出 | **错误** |
| A6 | 使用 `...` 代替 `……`、`--` 代替 `——` | 列出 | **错误** |
| A7 | 每章脚注数（原注）与原文差异 | 列出源/译数量 | 警告 |
| A8 | 每章图片数与原文差异 | 列出源/译数量 | 警告 |
| A9 | 连续 8 个以上英文单词的段落（疑似漏译） | 列出 | 警告 |
| A10 | `%% TODO` 遗留 | 计数 | 提示 |
| A11 | 章节文件缺失/为空 | 列出 | **错误** |
| A12 | 术语表字段缺失或重复 | 列出 | **错误** |

> “原注”统计：只数 `\footnote`。译者注用 `\zhu`，使用独立编号与 `\footnotetext`，不占用原注编号，也不参与原注计数。

### 1.3 退出码

- `0`：无错误（可有警告）；
- `1`：存在错误（A2/A4/A5/A6/A11/A12）；
- 构建脚本遇到 `1` 会提示，但默认仍保留已生成的 PDF。

### 1.4 误报处理

以下情况可忽略，但应在 `notes/decisions.md` 登记：

- 书名、机构名首次出现时括注原文（`\term{}{}` 内）；
- 参考文献、索引、术语表章节；
- 代码、URL、拉丁学名；
- 原文刻意保留的英文（如口号、标语）。

## 2. 人工检查

### 2.1 初译后（每章）

- [ ] 对照原文逐段过一遍，段落无遗漏、无错序
- [ ] 每句都有对应；没有“读起来像自己写的”句子
- [ ] 人名、地名、术语与 `terms.csv` 一致
- [ ] 脚注全部译出，编号与正文对应
- [ ] 图注、表注、图内文字说明完整
- [ ] 数字、年份、页码、引文出处准确
- [ ] 不确定处已标 `%% TODO`

### 2.2 双语审校（每章）

- [ ] 否定、双重否定、反义
- [ ] 情态与限定语（may / might / often / in some cases）
- [ ] 逻辑连接（因果、转折、让步、条件）
- [ ] 指代明确（this / it / they / the former）
- [ ] 引语边界、说话人、引文内省略
- [ ] 文化专有项处理（归化是否过度）
- [ ] 反讽与双关（是否被译直）
- [ ] 术语一致性（含新出现术语是否入表）
- [ ] 原注与正文引用关系
- [ ] 图表编号与正文引用

### 2.3 单语润色（每章）

- [ ] 朗读一遍，标记拗口处
- [ ] 长句拆分后逻辑仍清楚
- [ ] 无“的的不休”、被动泛滥、名词化堆叠
- [ ] 连接词不过量
- [ ] 代词指向清楚
- [ ] 段落节奏与原文大致对应
- [ ] 作者语气（冷静/讥讽/热情）保留
- [ ] 没有为顺口删信息

### 2.4 排版终检（全书）

- [ ] 封面、书名页、版权页、目录、正文、附录、术语表齐全
- [ ] 目录层级与页码正确
- [ ] 页眉：左页书名、右页章名；页码位置正确
- [ ] 章首页不显示页眉（或按项目体例）
- [ ] 脚注编号连续、跨页正常、未被裁切
- [ ] 每幅图清晰、位置合理、图注不分离
- [ ] 表格不溢出、长表跨页有表头
- [ ] 引文缩进与字体正确
- [ ] 无孤行、孤字、孤标题
- [ ] PDF 元数据（标题、作者、关键词）正确
- [ ] 随机 10 页与原文对照，无内容丢失

### 2.5 随机抽样复核（全书）

- [ ] `audit.py inventory` 各单元 `aligned=true`，或段落差异已记录
- [ ] 已用 `sample_size.py` 按目标残余率与置信度确定样本量
- [ ] 至少 3 轮抽样，覆盖率不低于设定阈值
- [ ] 每轮复核记录写入 `notes/audit/findings.csv`
- [ ] `stats` 的 `stop_recommended=true`，或未停止的理由已记录
- [ ] 抽样发现的问题已回到正文修正，并在后续轮次复验

### 2.6 交付前

- [ ] 已选择 `qa_mode`（full / sample / structural），并在 `project.json` 或交付说明中记录理由
- [ ] `check.py` 无错误
- [ ] `notes/progress.csv` 全部章节为「终检」
- [ ] `notes/decisions.md` 记录了所有重大命名/体例决策
- [ ] 术语表与译文一致（随机抽 20 条核对）
- [ ] 版本号已更新
- [ ] 源文件、PDF、术语表、卷宗一起归档

## 3. 缺陷分级与处理

| 级别 | 定义 | 例子 | 处理 |
|---|---|---|---|
| A（致命） | 改变原意、事实错误、漏译整段、注释/图缺失 | 否定译反、数字错、整段未译 | 必须修复，返工该章 |
| B（严重） | 逻辑不清、指代错误、术语不一致、风格明显失真 | “这”指错对象、同一术语两种译法 | 必须修复 |
| C（一般） | 搭配不当、标点错误、句子拗口 | 半角逗号、长句难读 | 修复或登记 |
| D（建议） | 可改可不改的润色 | 语序微调 | 记录，不强求 |

审校记录模板：

```markdown
## ch03 审校记录（2026-11-13）

| # | 位置 | 原文 | 初译 | 问题 | 改译 | 级别 |
|---|---|---|---|---|---|---|
| 1 | 第 2 段 | ... | ... | 否定译反 | ... | A |
```

---

## 4. 抽样规则

- 每章审校：100% 对照（书籍项目不做抽样）；
- 长篇文章（> 2 万字）：至少 30% 逐句对照 + 100% 通读；
- 终检：随机 10 页逐字对照 + 全书目视；
- 术语：每 5 章随机抽 20 条核对上下文。
