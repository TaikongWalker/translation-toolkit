# 排版规范（LaTeX）

## 1. 引擎与依赖

- 引擎：**XeLaTeX**（必须；`ctexbook` + `xeCJK` + `fontspec`）
- 编译：`latexmk -xelatex`，由 `scripts/build.ps1` 封装
- 页面：170 × 240 mm，双面，章起右页（`openright`）
- 西文：Palatino Linotype；中文正文：宋体（SimSun）；标题：黑体（SimHei）；引文：楷体（KaiTi）；等宽/仿宋：FangSong
- 说明：系统里的 Noto Serif/Sans SC 是可变字体（VF），`xdvipdfmx` 无法嵌入，故不使用。若安装了静态版思源宋体/黑体，可改 `preamble.tex` 的字体设置。

## 2. 文件组织

```
project/
├─ main.tex                 总装：文档类、导言区、front/main/back matter
├─ preamble.tex             版式与宏（通用，尽量不要逐项目大改）
├─ project.json             书目元数据（唯一来源）
├─ frontmatter/
│  ├─ cover.tex             封面
│  ├─ copyright.tex         版权与翻译说明
│  ├─ dedication.tex        献词（可选）
│  ├─ preface.tex           译者说明
│  └─ acknowledgments.tex   致谢（可选，存在则自动纳入）
├─ chapters/
│  ├─ ch01.tex …            每章一个文件，只写正文
│  └─ conclusion.tex        结论（不编号）
├─ backmatter/
│  ├─ glossary.tex          术语表外壳
│  ├─ bibliography.tex      参考文献外壳
│  ├─ index.tex             索引外壳
│  └─ afterword.tex         译后记
├─ generated/               脚本生成，勿手改
│  ├─ meta.tex              由 project.json 生成
│  ├─ chapters.tex          自动扫描 chapters/*.tex
│  ├─ glossary.tex          由 terms.csv 生成
│  ├─ bibliography.tex      由 source/backmatter/bibliography.md 生成
│  └─ index.tex             由 source/backmatter/index.md 生成
├─ figures/                 译稿用图
├─ source/                  原文档案（只读）
└─ dist/                    最终 PDF
```

## 3. 常用命令

```powershell
# 在项目目录
..\..\scripts\build.ps1                 # 生成元信息/术语表 → 编译 → 检查 → dist/
..\..\scripts\build.ps1 -Clean          # 清空 build 后完整重编
..\..\scripts\build.ps1 -Open           # 编译后打开 PDF
..\..\scripts\build.ps1 -NoCheck        # 跳过质量检查
..\..\scripts\build.ps1 -Strict         # 检查有错误时构建失败
```

PDF 被阅读器占用时，构建不会失败，而是写入 `dist/<slug>-<时间戳>.pdf`。

`build.ps1` 在编译前依次运行 `prepare.py`（元信息、章序、术语表）与 `backmatter.py`（参考文献、索引），因此 `generated/` 可随时清空重建。

## 4. 章文件写法

```latex
\chapter{章名}
\label{ch:01}

\section{节名}

正文段落。中文段落首行缩进由模板自动处理，不要手打空格。

\subsection{小节名}
```

- 不写 `\documentclass`、`\begin{document}`；
- 不手写“第一章”，编号由 `ctexbook` 生成；
- 结论等不编号章节：
  ```latex
  \chapter*{结论}
  \addcontentsline{toc}{chapter}{结论}
  \markboth{结论}{结论}
  ```
- 章文件按文件名自然排序（ch01, ch02, …, ch10），自动生成到 `generated/chapters.tex`；文件名含 `pilot` 的草稿不纳入成书。

## 5. 翻译专用宏

| 宏 | 用途 | 示例 |
|---|---|---|
| `\term{中文}{原文}` | 术语首次出现 | `\term{述行性}{performativity}` → 述行性（*performativity*） |
| `\orig{原文}` | 仅保留原文斜体 | `\orig{habitus}` |
| `\zhu{……}` | 译者注（独立编号，不占原注号） | `\zhu{俄语 вне，意为“在外”。}` |
| `\todo{……}` | 编译可见的待办 | `\todo{核对译名}` |
| `transnote` 环境 | 块级译者按语 | 见下 |
| `chapterquote` 环境 | 章首题词 | 见下 |
| `\figsource{……}` | 图注来源行 | `\figsource{图片来源：原书第 64 页。}` |

块级译者按语：

```latex
\begin{transnote}[译者注]
此处说明较长，不宜放进脚注。
\end{transnote}
```

章首题词（题词正文译出，出处保留原文）：

```latex
\begin{chapterquote}{——Gilles Deleuze and Félix Guattari, \textit{A Thousand Plateaus}}
题词译文……
\end{chapterquote}
```

**注意**：原文脚注每章从 1 重新编号，与原文对应；`\zhu` 使用独立的“译注”编号，不占用原注号。`check.py` 只统计 `\footnote` 来核对原注数量，所以译者注必须用 `\zhu`，不要直接写 `\footnote{译者注：……}`。

## 6. 图

```latex
\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.8\textwidth]{figures/fig2-1.jpg}
  \caption{图注译文。}
  \label{fig:2-1}
  \figsource{图片来源：原书第 64 页。}
\end{figure}

如图 \ref{fig:2-1} 所示……
```

- 图片放 `figures/`，也可直接引用 `source/images/`（模板已设 `\graphicspath`）；
- 图号沿用原书（图 2.1 → `fig:2-1`），便于对照；
- 图注、图内文字说明、来源行都要译；
- 图不要跨页，不与图注分离。

## 7. 表

三线表（`booktabs`）：

```latex
\begin{table}[htbp]
  \centering
  \caption{表题}
  \label{tab:1}
  \begin{tabular}{@{}lll@{}}
    \toprule
    列一 & 列二 & 列三 \\
    \midrule
    …… & …… & …… \\
    \bottomrule
  \end{tabular}
\end{table}
```

长表用 `longtable`，表头用 `\endfirsthead` / `\endhead` 重复。术语表就是自动生成的长表。

## 8. 引文

- 短引文：随文加引号；
- 长引文（> 3 行）：`quote` 环境，自动缩进、楷体、小字号；
- 引文内省略用 `……`，补充用 `〔〕`；
- 原文诗句/歌词：用 `quote`，逐行用 `\\` 换行；译诗不强行押韵。

## 9. 元数据

`project.json` 字段：

| 字段 | 说明 |
|---|---|
| `slug` | 文件名/PDF 名 |
| `title` / `subtitle` | 中文书名/副题 |
| `title_original` / `subtitle_original` | 原书名/副题 |
| `author` / `author_original` | 作者中文名/原名 |
| `translator` | 译者 |
| `publisher` | 译本出版者（可空） |
| `original_publisher` / `original_year` | 原出版者/原出版年 |
| `year` | 译本年份 |
| `version` | 版本号（0.1 初译 → 1.0 定稿） |
| `rights` | 版权状态 |
| `keywords` | PDF 关键词 |

构建时由 `prepare.py` 生成 `generated/meta.tex`，不要手改该文件。

## 10. 多格式导出

PDF 由 XeLaTeX 生成；EPUB / DOCX / HTML / Markdown 由 Pandoc 从同一份 LaTeX 稿导出：

```powershell
python ..\..\scripts\export.py --project . --format all
```

- 安装：`winget install JohnMacFarlane.Pandoc`；用 `--check` 验证
- 输出：`成品/<slug>/{md,html,epub,docx}`（`projects/` 结构下）；否则 `dist/`
- TikZ 图会先用 XeLaTeX 编译为 PNG 再嵌入；需要 `xelatex` 与 PyMuPDF
- 章节自动编号；脚注、译者注、图注、引文保留
- 版式简化：精确分页、双栏索引、字体排印只在 PDF 中保留
- 需要术语表/参考文献/索引时加 `--include-backmatter`

## 11. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `Font ... cannot be found` | 字体名不对或 VF 字体 | 用 Windows 自带宋体/黑体；或安装静态字体 |
| `xdvipdfmx:fatal: Invalid font` | 嵌入了可变字体 | 同上 |
| `I can't write on file chapters/ch01.aux` | 用了 `\include` + `-outdir` | 用 `\input`（模板已改） |
| 空白页有页眉 | `book` 类的 `\cleardoublepage` 不带 empty 样式 | 模板已重定义 |
| PDF 复制失败 | 阅读器占用 | 构建脚本自动写时间戳副本 |
| 术语表为空 | `terms.csv` 没有非 deprecated 条目 | 先填 draft 或 final；`prepare.py --final-only` 可只收定名条目 |
| 中文粗体发虚 | SimSun 无粗体，使用伪粗 | 可接受；或换有粗体的静态字体 |

## 12. 项目内定制

- 只改本项目版式：在 `main.tex` 的 `\input{preamble}` 之后加 `\input{project-style.tex}`，不要直接改公共 `preamble.tex`；
- 公共模板的改进（字体、宏、页面）改 `_template/` 与工作区 `scripts/`，并同步到已有项目（手动复制 `preamble.tex` 或记录差异）；
- 目录/插图目录标题、页眉、脚注格式都在 `_template/preamble.tex` 顶部集中定义。
